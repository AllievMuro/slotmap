CORE

Field-Level Breaking Change Reports

slotmap diff fetches live discriminator maps via Solana RPC, compares against your local IDL v2, and emits structured JSON reports showing exact borsh offsets, type mutations, and discriminator mismatches — not just "something changed."

🔗

On-Chain PDA Registry

Publish versioned schemas with slotmap publish. External teams at Kamino or Meteora subscribe to your program and get webhook alerts on any layout change.

🚦

CI/CD Pre-Deploy Gate

Anchor build hook integration exits non-zero on breaking changes. GitHub Actions template polls the registry and fails CI if a subscribed dependency has an unacknowledged schema mutation.

📡

Webhook & On-Chain Events

Downstream programs can read schema change signals via CPI. HTTP webhooks POST to your endpoint on every registered schema version bump — no polling required.

How Slotmap Works

01

Declare Schema

Run slotmap publish to register your Anchor IDL v2 as a versioned schema in the on-chain PDA registry.

02

Diff Before Deploy

slotmap diff fetches live mainnet state via RPC and computes field-level borsh layout deltas against your local IDL.

03

Gate the Pipeline

The Anchor build hook blocks deployment automatically if any registered downstream dependent would break from your changes.

04

Alert Subscribers

On schema publish, all registered dependents receive webhook POSTs and on-chain event signals so no team is caught off-guard.
